# 🔗 Browser URL Saver

A simple and lightweight **Chrome Extension** built with **HTML, CSS, and JavaScript** that allows users to save URLs directly in their browser for quick access later.

## 🚀 Features

* 🔗 Save URLs quickly
* 💾 Store saved URLs in the browser
* 📋 Display saved URLs
* 🌐 Open saved URLs with a click
* 🗑️ Delete saved URLs
* ⚡ Simple and lightweight interface

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**
* **JavaScript**
* **Chrome Browser**

## 📥 Installation

Follow these steps to install and run the extension locally.

### 1. Clone the Repository

```bash
git clone <your-repository-url>
```

Or download the repository as a ZIP file and extract it.

### 2. Open Chrome Extensions

Open Google Chrome and navigate to:

```text
chrome://extensions/
```

### 3. Enable Developer Mode

Turn on **Developer mode** using the toggle in the top-right corner.

### 4. Load the Extension

Click **Load unpacked**.

Select the project folder:

```text
Browser_Extension/
```

### 5. Start Using the Extension

Once the extension is loaded:

1. Click the **Extensions** icon 🧩 in Chrome.
2. Find **Browser URL Saver**.
3. Open the extension.
4. Enter a URL.
5. Click **Save**.
6. Click any saved URL to open it.
7. Use the delete option 🗑️ to remove a saved URL.
